# Tugas4_Kelompok-11
Aplikasi EcoWatt
aplikasi simulasi pemantauan energi listrik dari panel surya. Pengguna bisa mengubah kondisi panel, menekan kartu untuk melihat detail, menahan kartu untuk mengaktifkan mode fokus, dan menggeser panel surya untuk mengubah posisi serta simulasi produksinya.
Aplikasi ini mengangkat SDG 7 (Energi Bersih dan Terjangkau) serta SDG 13 (Penanganan Perubahan Iklim). Data yang ditampilkan berupa simulasi untuk keperluan demonstrasi, bukan pengukuran listrik sungguhan.
